# ⚡ BiteHub — Fast, Fresh & Out of This World 🍔🚀

BiteHub is a modern, cyberpunk-inspired fast-food web application built with **React** and **Vite**. Designed with an anti-gravity neon aesthetic, it delivers a seamless food ordering experience featuring localized Pakistani Rupee (PKR) pricing, real-time item customization, dynamic WhatsApp checkout receipts, and an integrated CRUD Admin Portal.

---

## ✨ Core Features

* 🛸 **Cyberpunk & Anti-Gravity UI:** Immersive dark-mode glassmorphic interface with neon glows, telemetry badges, and smooth micro-interactions.
* 📋 **Dynamic Food Vaults:** 25+ curated items across Pizzas, Smash Burgers, Loaded Fries, Beverages, and Desserts.
* 🛠️ **Customization Modal:** Real-time portion upgrades, spice calibration, and add-on selections (cheese, chili glazes, sauces).
* 🇵🇰 **PKR Pricing Engine:** Fully localized Pakistani fast-food pricing model with standard local delivery fee calculations.
* 📲 **Direct WhatsApp Transmission:** Generates encoded, itemized checkout receipts routed directly to the restaurant's WhatsApp dispatch queue.
* 🔐 **Integrated Admin Portal:** Passcode-protected dashboard (`PIN: 1234`) enabling full CRUD capabilities (Add, Edit, Delete, Restore Defaults) with `localStorage` persistence.
* 🛡️ **Fault-Tolerant Assets:** Built-in `onError` image fallback handlers to prevent broken image cards.
